# 视觉目标与开发计划

## 作品定义

XPIN-CHIP 是**3D 芯片解构 / 科普演示模板**，不是单个芯片展示页。以用户所示宣传片为基准：一层有重量、反射与立体文字的外壳，下面是一套可以直接读懂、可单独聚焦的玻璃化功能架构。既能当产品广告镜头，也能逐级解释 SoC。

### 内容层（每种芯片可独立替换）

- **Shell**：芯片形状与厚度、倒角、金属 / 陶瓷 / 漆面、边框、丝印、标识、Logo、带真实立体起伏的字与图案；贴图与矢量 / 几何图层可混用。
- **Die**：基板、die 表面微结构、已知的功能模块位置比例、嵌套结构与功能标识。玻璃既要能透出结构，又要保留体积、厚度、折射 / 反射、接触阴影。
- **Story**：模块解释、热点、相机目标、灯光状态、爆炸深度、显隐与解说顺序。

### 表现层

- 工业真实感：多尺度倒角、反射环境、Softbox、可控轮廓灯、AO / Contact Shadow、各表面独立 roughness / metallic / IOR。
- 架构可读性：玻璃/亚克力晶块 + 真实层级 + 合理分区线 + 精致微电路图案；一键提升单区对比而不淹没其他区域。
- 外壳细节：不是简单将完整宣传图铺在顶部。Logo、文字与装饰线作为可编辑材质/几何元素；依据资源支持贴花、浮雕、凹刻、镭雕和拉丝金属。
- 动画：外壳抬升、各层错位、模块独显、镜头推进和转向、说明线、重组；动作不穿模，镜头适应遮挡。
- 产品体验：右侧差点中文控件，常用项前置；无 UI 取景、一键还原、关键参数预设。

## 开发路线

### P0｜工程基线
可运行入口；类型定义、芯片数据文件、材质与交互解耦；通用 demo 的原点、尺寸与方向约定。仓库文档保持短小，Codex 可直接接续。

### P1｜V0.1 交互芯片
一枚示意通用 SoC：底座、可抬起外壳、CPU/GPU/NPU/ISP/Memory 等可编辑 block；玻璃/PBR；标签；鼠标轨道；点击聚焦、爆炸滑杆、层显隐、讲解切换。**验收以真的能操作为准**，并标明哪些细节仍是示意。

### P2｜V0.2 视觉精修（最高优先级）
针对用户上传的天玑/骁龙参考：外壳分层几何、边框与刻字、独立金属材质和细光；玻璃厚度、倒角、真实反射与阴影；die 微结构密度、线路层次、版图视觉真实性；相机 / 灯光预设和高级画面构图。输出几组可比较效果图；不要为了控制项数量牺牲成片审美。

### P3｜V0.3 图像到芯片
输入两类图片：
1. 官方芯片功能架构图：AI 提取模块名称、相对比例、边界、嵌套层级、可见文本；生成布局 JSON，允许人工纠正。官方框图 ≠ die 实际摄影或准确晶体管排布，按已知事实标记来源。
2. 外壳图片 / Logo / 印刷文件：AI 判断哪些是平面纹理，哪些应重建为向量轮廓、文字挤出 / 压印 / 金属；输出可单独调节的图层与光影层。无法恢复的字体/Logo形状需报告待校对项。

保留每个生成结果的证据来源、识别置信与人工修正入口；AI 改内容时尽量仅改芯片实例目录。

### P4｜V0.4 科普导演系统
独立摄影机和光照预设；模块特写、慢环绕、剖切/渐透、爆炸层级；讲解步骤支持任意时刻 seek、播放、暂停、倒放/复位；各状态可重复复现；最终给出固定分辨率及干净帧录制 / 图像序列出口。

## 后续增强（按实际需求）
导入高精度 GLB 零件、HDR 环境与材质资源、多个结构层级 / 子 die、光线追踪式高级预览、注释与镜头打包成复用 Preset、演示时长/台词 Marker。

## 成功标准
替换芯片时不修改核心场景代码；对外壳与 die 能独立美术指导；交互与影片镜头共享统一状态；用户拿到一张架构图和外观参考后，AI 可以产出可再次编辑的芯片实例，而不是一次性渲染图。
