# XPIN-CHIP｜三维芯片解构模板

可复用的交互式芯片三维演示系统：**品牌外壳 × 玻璃化内部架构 × 科普运镜 / 爆炸拆解**。

输入芯片架构示意图和外壳参考图，由 AI 将它们整理为可编辑数据与素材；在统一的 Three.js 场景中查看、聚焦、讲解、拆解和复原。以厂商级产品宣传片的光影与材质质量为长期目标。

## 工作方式

1. 提供芯片内部架构示意图、外壳图片 / 矢量图，以及已知的技术资料。
2. AI 对照来源整理模块布局、层级、标注和外壳设计元素，区分已核实信息与示意内容。
3. 用结构化数据生成三维 die / block 与独立外壳。外壳的金属底色、浮雕文字、图形材质、贴图均可独立配置。
4. 在网页中切换总览 / 外壳开启 / 爆炸视图，点击模块触发顺滑的特写运镜、局部高亮与注释。
5. 使用可定位时间线的演示镜头，并提供隐藏 UI 的视频画面。

**内容可替换，场景引擎复用。** 外壳、内部架构、标注、演示镜头、材质预设相互解耦。

## 开发约定

- 入口给观众用，控制面板给创作者用；中文 UI，常用参数前置、分类折叠。
- 技术基线：Vite + TypeScript + Three.js；优先浏览器实时交互与可编辑性。
- 结构、文字、布局和镜头配置优先数据驱动；难以通过单一图片正确恢复的几何应作为独立几何 / 文字 / Logo 元素重建。
- 光影和材质以实际参考为目标，明确区分真实 die 结构与示意可视化。
- 保持高质量的交互和动画：顺滑聚焦、合理爆炸距离、遮挡管理、镜头可手动接管。
- 有可用的官方素材、公开架构图或开源方案时优先复用；未经验证不把示意图解释成真实微观物理结构。

## 运行当前 Demo

本地安装 Node.js 20.19+ / 22.12+ 后：

```bash
npm install
npm run dev
```

打开 Vite 输出的地址。执行 `npm run build` 可检查 TypeScript 并生成 `dist/`。

**当前可操作内容：** 五款芯片切换、正方形闭合封装 / 展开架构 / 正面视图、全部模块特写与独显、三套布光、曝光、玻璃可见度与磨砂、可关闭 / 停止的数据流、参考顶盖 / 自定义文字 / 无标识、上传顶盖、步骤播放、H 隐藏 UI、PNG 导出。离线版可以把全部编辑和上传图片重新保存到一个 HTML 内。英文自定义字为挤出几何；中文自定义字为字体纹理。

**当前五款：** 天玑 9600 Pro、9600M、9500，第六代骁龙 8 至尊版、超级至尊版。9600 Pro 与骁龙的宏观布局对齐提供的参考图；9500 按官方模块标签重建同系列示意布局及顶盖；9600M 的未确认型号 / 容量不作推测。所有微电路均为程序化结构示意。内置厂商品牌顶盖为参考纹理及浅浮雕法线，复杂 Logo 尚不是独立挤出矢量模型。

五款芯片数据集中在 `src/chips.ts`，包括模块尺寸、核心分区、说明、品牌、顶盖选择及官方来源。场景与光学逻辑在 `src/main.ts`；旧版通用 demo JSON 保留在 `public/chips/demo/` 作历史例子，不再驱动当前五款场景。

## 单文件离线版

直接下载 **[XPIN-CHIP-Standalone.html](XPIN-CHIP-Standalone.html)**，双击用 Chrome / Edge 打开。Three.js、内置字体、Demo 芯片结构、CSS 与互动逻辑均已内嵌，**离线可运行，无需 npm、服务器、CDN 或其他文件**。

页面右侧切换五款芯片并调整材质、布光、数据流与顶盖。修改品牌 / 型号即进入自定义模式；清空可去字，选择“无标识”可去掉全部顶盖标识。各型号编辑在本次页面会话中独立保留；按“保存当前单 HTML”可把它们和当前镜头一起永久保存为新文件。中文显示依赖本机 CJK 字体。按 `H` 切换无 UI，隐藏后也可在右上角悬停恢复。

重新打包：`npm run standalone`。仅生成一个 HTML，包含 Three.js、字体、两张内置参考图片、五款架构和 CSS；运行不请求外部资产。官方来源链接只有手动点击时才联网。

本轮验收记录见 `PROGRESS.md`。实时 WebGL 是浏览器画面，未把它当成离线渲染宣传片质量的证明；`file://` 双击步骤受验收浏览器策略限制，未实测。

每次主仓库源码更新，GitHub Actions 会重新构建此离线 HTML。源代码仍在 `src/` 和 `public/chips/demo/` 中，便于 Codex 持续编辑。
